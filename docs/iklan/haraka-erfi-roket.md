# Iklan Haraka Erfi — "Roket" (Kapten Bagas)

Iklan maklon skincare, vertikal 9:16, ±22 detik, 3 klip Omni 1.1 Flash. Dibuat ulang dari naskah referensi bos setelah feedback (4 November 2026).

## Brief

- **Feedback bos:** naskah lama kurang greget. Unggulkan **HPP murah**. Roket maksudnya **pelayanan cepat**.
- **Pesan utama:** HPP murah. **Pesan pendukung:** proses cepat (roket).
- **CTA:** klik WhatsApp Haraka Erfi.

### Kenapa naskah lama kurang greget

1. Hook 5 detik dan lucunya ("dikirim ke bulan") tidak nyambung ke manfaat.
2. Roket dipakai sebagai "bisnis melesat", bukan "cepat".
3. HPP murah baru muncul di detik ke-18 dan bersaing dengan 4 pesan lain.
4. "Modal awalnya? Konsultasikan…" tidak memberi informasi.
5. Kalimat margin berbentuk disclaimer dan terlalu panjang untuk diucapkan.

### Perlu dikonfirmasi sebelum produksi

- [ ] "HPP mulai 25 ribu" angka asli Haraka Erfi? (di naskah referensi hanya contoh)
- [ ] Ada angka kecepatan (sampel X hari / produksi X minggu) untuk menggantikan kata "cepat"?
- [ ] Warna brand Haraka Erfi untuk aksen baju (sementara `#F26B1D`)

## Naskah

Konsep: HPP mahal = alarm bahaya di roket → Haraka Erfi memperbaiki → roket meluncur kencang (proses cepat).

**Klip 1 · Hook — HPP mahal (0–6 detik)**

| Visual | Dialog | Teks layar (editing) |
|---|---|---|
| Kokpit, alarm merah berkedip, Bagas panik memegang botol skincare | Bagas: "HPP skincare lu masih mahal? Pantes untungnya tipis!" | ⚠️ HPP MAHAL = UNTUNG TIPIS |
| | Operator (radio): "Tenang Bos, ke Haraka Erfi aja!" | |

**Klip 2 · Bukti — HPP murah (6–14 detik)**

| Visual | Dialog | Teks layar |
|---|---|---|
| Alarm jadi hijau, kalkulator melayang di gravitasi nol, Bagas menangkap dan menghitung | Bagas: "Di Haraka Erfi, HPP mulai 25 ribu. Jual 50 ribu, untung kotor 25 ribu per pcs!" | HPP mulai Rp25rb → jual Rp50rb = **+Rp25rb/pcs** · *ilustrasi, belum termasuk biaya lain* |

**Klip 3 · Roket = cepat + CTA (14–22 detik)**

| Visual | Dialog | Teks layar |
|---|---|---|
| Hitung mundur, mesin menyala, G-force, Bagas nyengir mengangkat produk, roket meluncur | Bagas: "Prosesnya ngebut kayak roket! Siapin nama brand lu, klik WhatsApp sekarang!" | PROSES CEPAT 🚀 |
| | Operator: "Tiga, dua, satu… meluncur!" | 👉 CHAT WHATSAPP HARAKA ERFI |

Jumlah kata dialog dalam kutip: 13 / 15 / 18 → autopilot memilih 6s / 8s / 8s.

### Variasi hook (A/B test, ganti klip 1 saja)

1. "HPP 40 ribu, jual 50 ribu? Itu mah capek doang, Bos!"
2. "Margin tipis? Masalahnya bukan di jualan lu, tapi di HPP!"
3. "Brand skincare sendiri, HPP mulai 25 ribu. Serius!"
4. "Mau bikin brand skincare tapi takut modal bengkak?"
5. "Tiga, dua, satu… cuan lu meluncur kalau HPP-nya pas!"
